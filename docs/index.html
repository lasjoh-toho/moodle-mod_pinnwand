Installation

  1. ZIP herunterladen und entpacken (ergibt einen Ordner pinnwand).
  2. Ordner nach <moodle>/mod/ kopieren (Ergebnis: <moodle>/mod/pinnwand/version.php).
  3. Als Admin einloggen → Website-Administration → Benachrichtigungen, Installation/Update bestätigen.
